# lab/game-world — 拉麵養成世界 M0 原型

單一 HTML 檔，零依賴，**不碰現有任何程式**。用來驗證 M1 的核心問題：
「在真實地理格子上走路去吃拉麵」到底好不好玩。

## 跑起來

要用本機伺服器開（頁面用 `fetch()` 讀棋盤，`file://` 會被瀏覽器擋）：

```bash
# 在 repo 根目錄
python -m http.server 8000
# → http://localhost:8000/lab/game-world/
```

棋盤來自 `data/boards/tpe-zhongshan.json`，由 `tools/board-gen/` 生成。

## 目前有什麼

| | |
|---|---|
| 地圖 | 中山區 239×245 格（25 m/格）。**只有道路能走**，陸地／水域／橋樑是風景 |
| 店門口 | 店家格不可通行。走到相鄰的道路格＝站在店門口才能踩點。並排店家被鄰居擋住的那一側自然不會是門口 |
| 移動 | 點地圖或右側店家 → A\* 找路 → 角色沿路走。**關掉分頁再回來，角色是「已經走到該走到的地方」** |
| 載具 | 走路 5／腳踏車 15／機車 30／捷運 60 km/h。移動中切換會依剩下的路重新計算 |
| 倍率 | 滑桿即時調 speedMultiplier（預設 x3），用來實際感受快慢 |
| 任務欄 | 依**實走距離**排序的店家清單，顯示距離與遊戲內耗時 |
| 踩點 | 走到店家格才能按，取得徽章 + 連續踩點 combo 加成（目前只存 localStorage） |
| 事件格 | 路上灑寶箱🎁／店家情報📣／路人👤／猜謎❓。經過即觸發，前三種自動收取，**猜謎會讓角色停下來**——全部自動收取的話玩家還是只能乾等 |
| 感知範圍 | 只看得到附近的事件（預設 800 m）。全圖都畫會被圖示淹掉，也沒有探索感；同時是之後可升級／可販售的能力 |
| 格線 | 夠近才畫並隨距離淡出。**看得到格子，階梯狀路徑才讀得成「棋盤走法」而不是「AI 不會走直線」** |
| 每日重生 | 事件格跨日全部長回來，走過的路才有再走一次的理由 |
| 手動設定位置 | 🧭 按鈕 → 在地圖上點一格，人物過去（不在路上會吸附到最近的道路）。載入時若角色不在路上也會自動修正——地形語意改過之後，舊存檔的位置會失效 |

## 刻意的設計

**通行性從 Tiled 的 tile property 讀，前端不寫死。**
在 Tiled 裡把一格從「陸地」改成「道路」，這頁就跟著變——只有一份真相。
門口也是現算的（與店家相鄰的道路格），所以你在 Tiled 改了路，門口跟著變。

**A\* 是 4 向，與 `tools/board-gen/verify.py` 同一套。**
兩邊必須走出同樣的路徑，否則玩家看到的距離與（正式版）伺服器算的抵達時間會對不上。
要改成 8 向的話兩邊得一起改。

**位置由「出發時間 + 每格秒數」推算，不是每幀累加。**
正式版同一套算法會搬到 Cloud Function：前端只負責內插動畫，
抵達判定與發獎在伺服器算，否則改系統時間就能無限刷幣。

**地形烘成離屏畫布再縮放繪製。**
58,555 格逐格 `fillRect` 撐不住 60 fps。每格加一點依座標決定的明暗抖動——
純色會讀成「一片地形」，有抖動才讀得出「一格一格」。

**沿路的每一格都檢查事件，不是只看「現在站哪格」。**
倍率高或分頁切回來時會一次跨過好幾格，中間的事件不能漏掉。

**鏡頭預設跟隨角色。**
不跟的話角色一走出畫面，路上撿到什麼玩家都看不到——而「路上有東西」
正是移動不無聊的全部理由。手動拖曳會暫停跟隨，按 ◎ 恢復。

## 還沒有的（M0 剩餘 / M1）

- Firestore：現在全部存 localStorage，沒有帳號、沒有同步
- 能量、硬幣（實體兌換）、每日任務、商城、換裝
- 事件格目前由格子索引雜湊決定（同一張棋盤永遠長出同一組，改密度就是換一組）。
  正式版改成從 Firestore 讀，好讓店家能指定「我門口這格放什麼」
- 猜謎題庫是佔位內容，正式版來自 `game/v1/quests`
- 美術：全部是色塊。M1 刻意如此——好不好玩跟畫得美不美無關，
  色塊版無聊的話再美的圖也救不回來
- 只有中山區一張棋盤
