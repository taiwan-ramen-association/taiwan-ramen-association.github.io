# lab/game-world — 拉麵養成世界 M0 原型

單一 HTML 檔，零依賴，**不碰現有任何程式**。用來驗證 M1 的核心問題：
「在真實地理格子上走路去吃拉麵」到底好不好玩。

## 跑起來

要用本機伺服器開（頁面用 `fetch()` 讀棋盤，`file://` 會被瀏覽器擋）：

```bash
# 在 repo 根目錄
python -m http.server 8000
# → http://localhost:8000/lab/game-world/
```

棋盤來自 `data/boards/tpe-zhongshan.json`，由 `tools/board-gen/` 生成。

## 目前有什麼

| | |
|---|---|
| 地圖 | 中山區 239×245 格（25 m/格）。拖曳平移、滾輪縮放、◎ 回到角色 |
| 移動 | 點地圖或右側店家 → A\* 找路 → 角色沿路走。**關掉分頁再回來，角色是「已經走到該走到的地方」** |
| 載具 | 走路 5／腳踏車 15／機車 30／捷運 60 km/h。移動中切換會依剩下的路重新計算 |
| 倍率 | 滑桿即時調 speedMultiplier（預設 x3），用來實際感受快慢 |
| 任務欄 | 依**實走距離**排序的店家清單，顯示距離與遊戲內耗時 |
| 踩點 | 走到店家格才能按，取得徽章（目前只存 localStorage） |

## 刻意的設計

**通行性從 Tiled 的 tile property 讀，前端不寫死。**
在 Tiled 裡把一格從「水域」改成「橋樑」，這頁就跟著變——只有一份真相。

**A\* 是 4 向，與 `tools/board-gen/verify.py` 同一套。**
兩邊必須走出同樣的路徑，否則玩家看到的距離與（正式版）伺服器算的抵達時間會對不上。
要改成 8 向的話兩邊得一起改。

**位置由「出發時間 + 每格秒數」推算，不是每幀累加。**
正式版同一套算法會搬到 Cloud Function：前端只負責內插動畫，
抵達判定與發獎在伺服器算，否則改系統時間就能無限刷幣。

**地形烘成離屏畫布再縮放繪製。**
58,555 格逐格 `fillRect` 撐不住 60 fps。

## 還沒有的（M0 剩餘 / M1）

- Firestore：現在全部存 localStorage，沒有帳號、沒有同步
- 能量、遊戲幣、每日任務、商城、換裝
- 美術：全部是色塊。M1 刻意如此——好不好玩跟畫得美不美無關，
  色塊版無聊的話再美的圖也救不回來
- 只有中山區一張棋盤
